データ削除手順

本サービス「スレッズスケジューラー」では、ユーザーのデータはすべてユーザー自身のGoogleアカウント内（Googleスプレッドシートおよび Google Apps Script のScript Properties）に保管されます。以下の手順により、ユーザーご自身でいつでもすべてのデータを削除いただけます。

制定日: 2026年4月29日
最終更新日: 2026年4月29日
事業者: BridgeSquare
連絡先: tamagoojiji@gmail.com

1. 投稿予約データの削除

本サービスで使用しているGoogleスプレッドシートを、Google ドライブ上で削除してください。

  1. Google ドライブ（https://drive.google.com/）を開く
  2. 「スレッズスケジューラー」のスプレッドシートを右クリック
  3. 「ゴミ箱に移動」を選択
  4. ゴミ箱を空にする（完全削除）

2. Threads APIアクセストークンの削除

スプレッドシートを削除すると、紐づく Google Apps Script およびそのScript Properties（アクセストークンの保管領域）も同時に削除されます。追加の操作は不要です。

3. Threads（Meta）側でのアプリ連携の解除

念のため、Threads アカウント側でも本アプリの連携を解除することを推奨します。

  1. Threads アプリまたは Web 版にログイン
  2. プロフィール → 設定 → 「アプリとウェブサイト」
  3. 本サービスのアプリを選択して「削除」

4. Meta Developer Platform 側でのアプリ削除（任意）

Threads API アプリそのものも不要であれば、以下の手順で削除できます。

  1. Meta for Developers（https://developers.facebook.com/）にログイン
  2. 「マイアプリ」から該当アプリを選択
  3. 「設定 → ベーシック」最下部の「アプリを削除」をクリック
ご注意: 本サービスは、ユーザーのデータを当方が運営するサーバーに保存していません。すべてのデータはユーザー自身の Google アカウント内に保管されているため、上記手順を実施いただくことで完全に削除されます。

削除手順がご不明な場合や、削除に問題が生じた場合は、以下の窓口までご連絡ください。
